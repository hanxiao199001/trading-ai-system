# 参数优化脚本使用说明

## 📋 文件说明

已创建两个优化脚本:

1. **optimize_params_standalone.py** (推荐先用这个)
   - 独立运行,不依赖你的现有代码结构
   - 包含简化的回测引擎
   - 可以直接测试参数效果

2. **optimize_parameters.py** (完整版)
   - 需要适配你的策略类
   - 使用你现有的回测引擎
   - 更准确,但需要调整代码

## 🚀 快速开始

### 方法1: 使用独立版本 (推荐)

```bash
# 1. 修改脚本中的数据文件路径
# 打开 optimize_params_standalone.py
# 修改第 295 行: DATA_FILE = 'data/btc_usdt_1h_90d.csv'

# 2. 运行优化
python optimize_params_standalone.py
```

### 方法2: 集成到现有项目

```bash

cp optimize_parameters.py /path/to/trading-ai-system/

# 2. 修改导入路径(第 12-16 行)
# 3. 运行
cd /path/to/trading-ai-system
python optimize_parameters.py
```

## 🎯 优化目标

### 稳健性评分公式 (0-100分)

```python
稳健得分 = 回撤得分(50%) + 胜率得分(30%) + 收益得分(20%)

回撤得分:
  - ≤ 1.5%: 50分
  - ≤ 2.0%: 40分
  - ≤ 3.0%: 30分
  - > 3.0%: 递减

胜率得分:
  - 60%胜率 = 30分 (满分)

收益得分:
  - ≥ 10%年化 = 20分 (满分)
  - 5-10%年化 = 10-20分
```

## ⚠️ 注意事项

1. **过拟合风险**: 
   - 参数在历史数据上表现好,不代表未来也好
   - 建议用不同时间段的数据进行验证

2. **样本外测试**:
   - 将数据分为训练集(70%)和测试集(30%)
   - 在训练集上优化参数
   - 在测试集上验证效果

3. **参数稳定性**:
   - 如果最佳参数在网格边界上,说明范围不够
   - 应该扩大范围重新优化

4. **交易次数**:
   - 如果交易次数太少(<10笔),统计意义不大
   - 考虑扩大数据范围或放宽条件

## 🔍 结果分析示例

假设得到以下TOP3结果:

```
第1名: trend=0.35, stop=0.015, take=0.025 → 年化8.3%, 回撤1.87%
第2名: trend=0.40, stop=0.020, take=0.025 → 年化7.8%, 回撤1.65%
第3名: trend=0.35, stop=0.020, take=0.030 → 年化8.7%, 回撤2.12%
```

**分析**:
- 第1名和第2名回撤接近,但第1名收益更高 → 选第1名
- 第3名收益最高,但回撤超过2% → 不符合稳健目标
- 如果想更保守 → 选第2名(回撤最低)
