# 现货期货套利策略说明

## 📊 策略原理

### 核心逻辑

现货期货套利是一种**市场中性策略**,通过捕捉现货和期货之间的价差进行无风险套利。

```
当期货溢价 > 0.5%:
  做空期货 + 做多现货 
  → 等待价差收敛 → 获利平仓

当期货折价 > 0.5%:
  做多期货 + 做空现货
  → 等待价差收敛 → 获利平仓
```

### 为什么价差会收敛?

1. **套利资金涌入**: 大量套利者发现机会后,会推动价差回归
2. **交割机制**: 永续合约通过资金费率,期货合约通过实物交割,确保价格最终收敛
3. **市场规律**: 长期看,期货和现货价格必须趋同

---

## ✅ 策略优势

### 1. 市场中性
- 不需要预测涨跌方向
- 只赚价差,不受市场波动影响
- 牛市熊市都能盈利

### 2. 低风险
- 双边对冲,风险对冲
- 不怕极端行情(上涨亏期货,赚现货;下跌相反)
- 只要价差收敛就盈利

### 3. 高胜率
- 理论胜率可达70-90%
- 价差收敛是确定性事件
- 适合稳健型投资者

### 4. 易量化
- 信号明确(价差阈值)
- 容易自动化
- 回撤可控

## ⚠️ 风险与注意事项

### 风险1: 价差持续扩大

**场景**: 极端行情下,价差不但不收敛,反而继续扩大

**应对**:
- 设置止损(2-3%)
- 控制仓位(不超过30%)
- 最大持仓时间(72小时强制平仓)

### 风险2: 手续费侵蚀

**场景**: 小价差(<0.3%)情况下,手续费吃掉大部分利润

**应对**:
- 只在价差>0.5%时开仓
- 选择低手续费交易所
- 使用VIP等级降低费率

### 风险3: 资金占用

**场景**: 双边开仓需要2倍资金

**应对**:
- 合理分配资金
- 不要满仓
- 预留应急资金

### 风险4: 流动性风险

**场景**: 现货或期货流动性不足,无法及时成交

**应对**:
- 只交易主流币种(BTC/ETH)
- 避开深夜交易
- 设置最小成交量要求
